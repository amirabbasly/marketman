# Marketman

A Persian, RTL software studio website built with Next.js App Router.

## Development

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build, then `npm start` to serve it.

## Content to customize

The business contact email is an example and the phone number is intentionally not invented. Replace them with verified details before publishing. Pricing is inquiry-based; partner, testimonial, team, blog and technology-news content should be updated with real details as they become available. Most landing-page content is in `components/Site.tsx`; secondary pages are in `app/[slug]/page.tsx`.
